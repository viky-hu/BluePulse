# Blue Pulse 使用说明

当前项目有 Next.js 前端和重新建立的 Python 后端。后端具备数据库、离线 mock 处理、匿名阅读接口，以及 15 个需显式触发的限量真实采集入口；分类模型和五轴双评分已在隔离库进行少量真实调用。2026-11-06 本机已改用 `backend/data/bluepulse.db` 新开发库，完成迁移及七类目录初始化，目前 0 个来源、0 篇材料。队友报告中的真实数据未随 Git 同步；新增来源的许可仍默认关闭，定时任务未注册。旧版后端采集说明可在 Git 历史中查阅，当前运行步骤见[后端说明](../backend/README.md)。

## 启动

在项目根目录安装依赖后，双击 `启动BluePulse.bat`，或在 PowerShell 中运行：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

网页地址为 <http://127.0.0.1:3000/>。启动脚本只启动前端；需要 API 时，按后端说明另开终端启动 `127.0.0.1:8000`。要停止网站，关闭其终端窗口或按 `Ctrl+C`。

本机新开发库已经初始化，后端启动命令为：

```powershell
cd D:\pulse\backend
.\.venv\Scripts\python.exe -m uvicorn bluepulse_backend.api:app --host 127.0.0.1 --port 8000
```

未设置 `BLUEPULSE_DATABASE_URL` 时会自动连接新库，无需设置额外变量。数据库属于本机运行文件，不纳入 Git；其他机器仍需按后端说明执行迁移和目录初始化。

## 阅读与演示

- 默认地址尝试读取真实 API。若后端未启动，精选、文章、搜索等页面会显示不可用；后端启动但没有正式数据时返回真实空态。离线 mock 检查不写正式数据库。
- 显式在页面地址添加 `?mock=1` 可查看演示数据。演示内容不应被当作真实采集结果或正式精选。
- 收藏、已读、浏览历史和首次封面状态保存在当前浏览器；清除浏览器数据或换设备后不会自动同步。
- 热点榜、AI 日报、Agent 接入和反馈当前显示建设状态，尚未接入相应真实服务。

## 接入数据服务

前端默认把 HTTP 请求发往 `http://127.0.0.1:8000/api/v1`。使用其他后端地址时，在运行前端的环境中设置 `BLUEPULSE_API_URL`。浏览器中的主界面通过同源 `/api/bluepulse/*` 代理读取受控 GET 路径，部分独立阅读页由 Next.js 服务端直接读取 API。接口字段、错误和待建能力见工作区根目录的 `后端需求.md` 第 10 节；当前实际实现范围见后端 README。

不要把数据库或模型密钥放入 `NEXT_PUBLIC_*` 环境变量。新增公开页面接口时，同步更新代理白名单、前端响应类型和后端契约；管理写操作应使用独立鉴权接口。
