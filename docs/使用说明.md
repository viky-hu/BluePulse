# Blue Pulse 使用说明

当前项目有 Next.js 前端和重新建立的 Python 后端。后端具备数据库、离线 mock 处理、匿名阅读接口，以及 15 个需显式触发的限量真实采集入口；分类模型和五轴双评分已在隔离库进行少量真实调用。2026-11-06 本机已改用 `backend/data/bluepulse.db` 新开发库，完成迁移及七类目录初始化，目前 0 个来源、0 篇材料。队友报告中的真实数据未随 Git 同步；新增来源的许可仍默认关闭，定时任务未注册。旧版后端采集说明可在 Git 历史中查阅，当前运行步骤见[后端说明](../backend/README.md)。

## 启动

首次使用先按[后端说明](../backend/README.md)安装 Python 环境并初始化数据库，再在项目根目录安装前端依赖：

```powershell
pnpm install --frozen-lockfile
```

然后双击根目录 `Pulse.bat`。脚本先检查并启动 `127.0.0.1:8000` 后端，等待健康检查通过后再启动 `127.0.0.1:3000` 前端，两者就绪后自动打开浏览器；已启动的服务会复用。后端未就绪时会提示检查依赖、数据库迁移或端口，不会继续打开尚不可用的网页。保留 API 和 Web 服务窗口；停止时分别关闭窗口或按 `Ctrl+C`。脚本只启动阅读服务，采集、模型及自动任务仍由独立操作触发。

本机新开发库已经初始化，后端启动命令为：

```powershell
cd D:\pulse\backend
.\.venv\Scripts\python.exe -m uvicorn bluepulse_backend.api:app --host 127.0.0.1 --port 8000
```

未设置 `BLUEPULSE_DATABASE_URL` 时会自动连接新库，无需设置额外变量。数据库属于本机运行文件，不纳入 Git；其他机器仍需按后端说明执行迁移和目录初始化。

## 阅读与演示

- 默认地址尝试读取真实 API。若后端未启动，精选、文章、搜索等页面会显示不可用；后端启动但没有正式数据时返回真实空态。离线 mock 检查不写正式数据库。
- 显式在页面地址添加 `?mock=1` 可查看演示数据。演示内容不应被当作真实采集结果或正式精选。
- 收藏、已读、浏览历史和首次封面状态保存在当前浏览器；清除浏览器数据或换设备后不会自动同步。
- 热点榜、AI 日报和反馈的完整真实服务仍待接入。Agent 接入已提供 HTTP 说明、近期资讯与标题／摘要搜索，本机空库可真实返回无结果；MCP、RSS 暂不展示。

## 接入数据服务

前端默认把 HTTP 请求发往 `http://127.0.0.1:8000/api/v1`。使用其他后端地址时，在运行前端的环境中设置 `BLUEPULSE_API_URL`。浏览器中的主界面通过同源 `/api/bluepulse/*` 代理读取受控 GET 路径，部分独立阅读页由 Next.js 服务端直接读取 API。接口字段、错误和待建能力见工作区根目录的 `后端需求.md` 第 10 节；当前实际实现范围见后端 README。

不要把数据库或模型密钥放入 `NEXT_PUBLIC_*` 环境变量。新增公开页面接口时，同步更新代理白名单、前端响应类型和后端契约；管理写操作应使用独立鉴权接口。

## Agent HTTP 接入

首次使用本次更新时，先停止已有 API 和 Web 进程，再双击 `Pulse.bat`。脚本只在环境未设置时，将本地 `BLUEPULSE_SITE_ORIGIN` 明确设为 `http://127.0.0.1:3000`，供两个子进程共同继承。已有服务仍会被复用，无法在运行中继承新变量，因此必须先重启；本次不自动终止用户现有进程。

打开 `/agent`，复制页首 Markdown 地址或提供的指令交给具备联网／命令行权限的 Codex。说明地址是 `http://127.0.0.1:3000/api/v1/agent`；JSON 示例及字段见 `/agent?tab=api`。接口匿名只读，不要求 Key，不触发采集或模型。当前空库返回 `items: []`；这表示没有结果，不表示连接失败。

手工启动时，在启动前端和后端的**两个终端**分别设置同一变量：

```powershell
$env:BLUEPULSE_SITE_ORIGIN = 'http://127.0.0.1:3000'
```

再按前文启动后端，并在根目录执行 `pnpm dev`。前端缺少地址会显示未配置；后端缺少或拒绝该配置时三个 Agent 路由均返回 503。`pnpm dev`、`next start` 和后端不会自动回退到本机站点地址；本地默认仅属于 `Pulse.bat`。如设置自定义域名，必须保证它真实路由到该站点。

Windows CMD／PowerShell 可执行：

```powershell
curl.exe "http://127.0.0.1:3000/api/v1/agent"
curl.exe "http://127.0.0.1:3000/api/v1/agent/latest?window=7d&limit=10"
curl.exe "http://127.0.0.1:3000/api/v1/agent/search?q=%E8%AD%A6%E5%8A%A1%E6%8A%80%E6%9C%AF&window=all&limit=10"
```

本机地址只供同一设备访问。公网需另配置固定 HTTPS 地址、精确路由、限流和超时并完成外部客户端联调；不要把本机地址交给远程 Agent。[DOCK-010](../dock.md#dock-010agent-http-接入页) 记录待办与验收边界。
