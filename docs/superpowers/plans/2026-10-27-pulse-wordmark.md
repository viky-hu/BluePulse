# Pulse 定制字标执行记录

**目标：** 按用户已确认的方案交付 A 连动、B 回响、C 波形三套独立字标，供视觉选择。

**做法：** 手工绘制 Bézier 字形轮廓，生成无字体依赖的 SVG；通过本地静态 HTML 展示原大、24px 菜单应用、黑白和反白效果，再渲染对比 PNG。所有产物放在 `docs/brand/pulse-wordmark/`。

**边界：** 在 main 工作；不接入站点、不修改现有菜单、入口动效或 qlxf.svg；不添加运行依赖。Google Sans 仅用于预览说明文字，不参与字标轮廓。

- [x] 绘制三套原创路径，A 使用 u–l 连笔，B 使用独立字母和重复弧线，C 使用轻微前倾与曲线起伏。
- [x] 输出三个主 SVG 和黑白、反白版本，以及响应式本地预览。
- [x] 在桌面、移动端、reduced-motion 下检查预览；检查所有字形没有裁切、24px 状态可读、SVG 没有文字或外部资源。
- [x] 渲染并人工查看对比图和单稿细节，按实际结果调整路径。
- [x] 执行 lint 和生产构建，记录交付边界与验证结果。

用户在预览期间选定 C · 波形（“简约大气”），追加输出 C 的正式命名主文件和透明 PNG。保留三稿对比，标记 C 为已选定稿，尚未接入网站。

验证：`pnpm lint` 与 `pnpm build` 均退出 0；浏览器检查桌面、移动和 reduced-motion 通过；12 份 SVG 的 XML 均可解析，C 主文件与候选文件哈希相同。已人工查看桌面对比、移动长图、A 细节与 C 定稿展示。当前分支 main；网站已有代码未修改。
