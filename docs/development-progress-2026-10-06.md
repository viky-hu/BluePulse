# BluePulse 开发进度记录（2026-10-06）

本文记录截至本次提交的代码和本地验证结果，不把“已配置的信源”或“已有接口”直接等同于稳定生产可用。范围以[执行路线](bluepulse-execution-roadmap.md)和[Stage1／Stage2 总路线](stage2-plan.md)为准；具体操作见[使用说明](使用说明.md)。

## 目标与当前结论

当前优先目标是完成“公开资讯采集 → 正文/摘要清洗 → 相关性与七主题分类 → SQLite 存储 → 首页/文章库/详情展示 → 原文追溯”的文字内容闭环。代码和离线测试已覆盖这条基本链路，开发库也有真实来源文章；但信源可达性、模型服务、Windows 长时间运行、PostgreSQL 和管理权限等仍未达到 Stage1 整体验收门槛。Stage2 的事件、项目和证据关系尚未启动。

用户已决定首版**暂不投入图片展示**。已有媒体模型、个别来源图片元数据和历史前端媒体路径保留，但图片抓取完整度、缩略图和媒体状态不作为近期完成条件；优先保证文字可查、可读、可追溯。

## 本轮验证证据

- 后端离线测试：`python -m unittest discover -s tests -q`，81 项通过，涵盖采集到公开 API、任务锁/幂等/过期接管、FTS 迁移及新增/更新/删除同步、翻译状态等。
- 前端类型检查：`npx tsc --noEmit` 通过；`npm run build` 成功生成首页、文章库、详情、实体页与 API 代理路由。
- 本地开发库：迁移到 `0007_article_search_status`；只读核对时 114 篇文章均进入全文索引，英文 `drone` 检索得到 2 条命中。该数字只是本机快照，不是信源质量或生产覆盖率指标。
- 真实外站与模型联调记录分散在[来源及操作说明](使用说明.md)、[人工校准记录](selection-calibration-2026-10-01.md)和[执行路线](bluepulse-execution-roadmap.md)。离线测试通过不代表所有外站当前可达。

## 下一步和验收缺口

1. 用代表性中英文真实样本做一次可重复的浏览器端到端验收，核对检索、筛选、翻译失败、缺正文、原文链接和移动端阅读；记录错误而不是用 mock 代替。
2. 对模型相关性与精选标准扩大人工样本评测；保存更完整的判断理由、版本和调用预算，减少重试重复成本。
3. 补管理员权限、运行查询、人工纠错、软删除和审计；目前仍以本机受控命令操作。
4. 若切换 PostgreSQL，单独实现并验证对应全文索引、迁移、分页及锁并发；不要把 SQLite 的本地结果当作 PostgreSQL 验收。
5. 图片展示暂缓；HTX 等新来源按公开接口稳定性与站点许可评估，信源扩充不替代上述内容和运行验收。

结论：**Stage1 的文字内容闭环已可本地试用，Stage1 整体验收未完成；Stage2 未开始。**
