# 正式“其它”分类接入

## 原始源码与 Pulse 适配

本轮依据本地 AIHOT 下载快照核对 `industry/taxonomy.ts`、`industry/prompts/structure.md`、`packages/backend/src/editorial/analyze.ts` 及 `publication/{rules,publish}.ts`。AIHOT 的公开类别为模型、产品、行业、论文、教程、观点，结构化结果可以为 null；另有“其他”标签，但不是“其它”公开类别。其发布判断不要求 category 非空。这里只说明静态源码行为，不代表线上运行验证。

Pulse 采用用户确认的八类方案：产品、实战、论文、法制、具身、舆情、低空、其它。相关性筛选与精选价值判断保留现状，自动分类输出一个主要类别；前七类都不贴切时，模型明确输出 `other`。普通警务报道不能通过选择“其它”绕过相关性判断。

## 接通的行为

- 生产结构化提示词及兼容分析入口接受 `other`，提示词按现有哈希方式产生新版本；结构化的缺失、null、非法类别统一报 `invalid_structure_category`，进入现有失败任务与人工恢复入口。管理界面显示中文原因，失败不会静默应用为“无关”或“其它”。付费响应仍先保存，相关错误不会触发盲目自动重试。
- 分类目录通过现有 `sync-taxonomy` 幂等注册 `other`；不改变数据库表结构，不批量更新材料、旧分类或人工覆盖。管理员的合法分类与数量限制同步扩至八类。
- 精选、全部动态及搜索的共享筛选追加“其它”，既有查询参数为 `topic=other`。分类卡片与有全文资格的阅读页显示“其它”；仅摘要阅读页继续遵守原有展示规则，不扩大全文许可。
- 直接打开末尾分类链接或改变窗口宽度时，筛选栏自动横向露出当前选项；不滚动正文，原有选中动效保留，观察器在切换和卸载时清理。
- 日报将新 `other` 文章放入“其它警务科技”分节；旧刊使用的 `unclassified` 仍保留，不回写已发布刊物。演示入口仍明确隔离，不作为真实业务结果。
- 标注 HTML 已使用 `other`，无需改动或改名。其120条材料、原文与辅助中文、既有记录和导入导出保持原样。评分内部七种内容类型与公开八类不同，评分权重和60／65／76门槛未改。
