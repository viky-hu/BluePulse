## 可复现操作

在 `backend` 目录、已初始化且指向目标业务库的环境中，先只读预览：

```powershell
python -m bluepulse_backend.cli daily-range --from-date 2026-11-01 --through-date 2026-11-15 --historical-source-dates
```

核对预览后执行：

```powershell
python -m bluepulse_backend.cli daily-range --from-date 2026-11-01 --through-date 2026-11-15 --historical-source-dates --execute --reason "基于已核实原站发布日期重建2026年11月1日至15日日报"
```

历史模式是显式的一次性编排选项，不改变默认新刊的首次收录归期；后续 worker 补刊从已保存的 `inputMode` 读取模式。重复运行只在内容发生变化时增加刊期版本，并保留旧版本。
