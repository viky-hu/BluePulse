# Blue Pulse

Blue Pulse 是一个面向国内外警务科技情报展示的前端项目。当前技术栈为 Next.js 16.3.5、React 19、TypeScript、Tailwind CSS 4 与 GSAP 3.15。

## 本地开发

```bash
pnpm dev
```

默认开发地址：<http://localhost:3000>

生产检查使用：

```bash
pnpm lint
pnpm build
```

## 项目约定

- 英文界面字体使用项目内置的 Google Sans 可变字体，由 `next/font/local` 加载，不依赖访问者运行时连接 Google。字重范围为 400–700，首屏展示文字默认使用 400。
- 中文字体优先使用 `"Microsoft YaHei"`（微软雅黑）。
- 大型标题作为独立 SVG 场景元素处理，默认常规字重、字距为 0，便于与色块边界和时间轴精确同步。
- 桌面构图以用户笔记本全屏 34 x 19 的实测比例为设计参考，代码中换算为响应式尺寸，不使用 CSS `cm`。移动端使用独立的安全边距和动态视口约束。
- 路由入口保持精简；页面组件、SVG 场景、动画编排、配置与局部样式按职责共置拆分，避免把整页逻辑堆进单个 TSX 或全局 CSS。
- 动画优先采用 GSAP 官方 API、插件和 React 生命周期实践。修改前先阅读对应 Skills、现有实现及本地文档；不重复实现成熟插件已经解决的底层能力。
- `qlxf.svg` 是 Logo 几何真值。它的 `3621 x 4252` viewBox、三条闭合 path、原始 `d` 数据与 `vector-effect="non-scaling-stroke"` 均应保留。
- 验收聚焦视觉与动效：常规变更完成后执行 lint、生产构建，并检查一个桌面视口、一个移动视口和 reduced-motion 状态即可。

## SVG 双场景裁切换色

参考登录页采用的并不是已经转曲的 path 字体。其当前标题是 SVG `<text>`：同一组内容在完全一致的坐标中渲染两次，一份作为基础场景，另一份作为反色场景；色块与反色场景共用同一个动态 `clipPath`。当色块边界移动时，裁切区域同步变化，因此文字在边界两侧显示不同颜色，而且不会发生位置漂移。

这套结构可用于标题、插图或其他需要随覆盖色块同步换色的 SVG 内容：

1. 渲染未裁切的基础场景。
2. 渲染覆盖色块，并用动态 `clipPath` 控制其可见区域。
3. 在相同坐标再次渲染反色场景，绑定同一个 `clipPath`。
4. 只驱动共享裁切边界，色块与反色内容便会严格同步。

字符动画使用两套索引一致的 `<text>/<tspan>` 节点。每个字符对同时执行 GSAP stagger，既能获得类似 SplitText 的逐字效果，也能继续保持 SVG 双场景的几何一致性。GSAP SplitText 主要拆分 HTML 文本，不直接承担这里的 SVG `<text>` 拆分。

## 初始页面

首屏是一段只播放一次的全屏 SVG 与 GSAP 时间轴。页面真实底色为 `#F2F2F2`，首帧由 `#353330` 幕布完整覆盖，防止浅色背景或完成态 Logo 在样式、字体或 hydration 就绪前闪现。

场景从下到上的主要层级为：

1. `#F2F2F2` 页面底色。
2. `#353330` 全屏幕布。
3. 居中的浮动矩形。
4. 英文标题与中文副标题。
5. Logo 和按钮交互层。

### 入场时间轴

- Logo 使用 `qlxf.svg` 的三条闭合路径和 DrawSVGPlugin 进行描边：绘制 1.8 秒，停留 0.6 秒，再于 0.25 秒内淡出。闭合路径的具体处理依据根目录的《GSAP闭合SVG描边动画方法论.md》。
- Logo 淡出后，`Blue Pulse` 和“国内外警务科技情报系统”立即按字符快速进入。英文使用 Google Sans 400，中文使用微软雅黑 400；深色幕布区域的文字颜色为 `#D5AF86`。
- 标题通过坐标一致的双层 SVG `<text>/<tspan>` 与幕布共享裁切边界，因此幕布移动穿过标题时能同步换色。
- 标题入场时，居中矩形从约 96% 尺寸扩张并淡入，按钮同步淡入。

### 浮动矩形

- 矩形是独立可复用的 SVG 组件，无圆角，宽高比为 2:3，并始终保留柔和阴影。
- 桌面宽度按 34 x 19 设计基准换算；移动端以 16px 水平安全边距和动态视口高度重新约束，避免溢出。
- 它同时渲染 `#FDFDFD` 基底和由幕布共享裁切区域限制的 `#353330` 皮肤。幕布退出时，矩形下方已露出的部分会同步恢复为 `#FDFDFD`。

### 交互与退出

- 圆形按钮位于矩形下边界上方，内部为两枚循环向下箭头；圆环、箭头与 hover 状态均为白色。
- 按钮点击、向下滚轮、移动端上滑、Enter 和 Space 都调用同一个一次性退出动作。入场完成前不接受退出；退出开始后立即禁用所有入口并忽略重复触发。
- 退出时标题与按钮先快速淡出，幕布下边界与矩形深色皮肤的共享裁切高度随后同步向上收缩。
- 最终状态只保留 `#F2F2F2` 页面底色与带阴影的 `#FDFDFD` 矩形，不自动重播，也不预先填入业务内容。
- `prefers-reduced-motion` 下直接显示静态封面；用户触发退出时立即切换到最终状态。

动画实现应使用 `useGSAP` 的组件 scope，并在卸载时清理时间轴、Observer、字体等待回调和 resize 监听。视口尺寸变化时重算 SVG 几何，同时保留 0–1 的退出进度，避免旋转或缩放窗口后重新播放首屏。
